This Tampermonkey script hides YouTube's `+5s`/`-5s` rewind indicator and keeps the controls visible while rewinding the video thus mimicing old YouTube GUI.

# Installation
1. Install the Tampermonkey extension for your browser.
2. Click Click [**Inatall script**](../../raw/main/remove_yt_rewind_indicator.user.js) to install or update the script.
If Tampermonkey is installed and enabled, it should open the installation page.
4. Select **Install**.
5. Reload YouTube.
